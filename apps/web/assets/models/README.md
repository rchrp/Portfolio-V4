# 3D models

## monitor_iii.glb

"Monitor III"
(https://sketchfab.com/3d-models/monitor-iii-fb119750ac4f4b1e89b4be7c870b4eb2)
by re1monsen (https://sketchfab.com/re1monsen) is licensed under Creative
Commons Attribution 4.0 (http://creativecommons.org/licenses/by/4.0/).

This is the original file as downloaded from Sketchfab. Its adapted version,
`public/models/monitor.glb`, is generated by `scripts/build-model.mjs` (ground
plane and floor cable removed, transforms baked, screen glass split into its
own primitive with a second UV set, unseen rear faces dropped, meshes
simplified and quantized, textures converted to WebP) and is credited in the
site's footer. Neither file is covered by the MIT license of the repository's
source code.
