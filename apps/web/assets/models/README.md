# 3D models

## monitor_iv.glb

"Monitor IV"
(https://sketchfab.com/3d-models/monitor-iv-c22e137779e7439b8825bf734de9a471)
by re1monsen (https://sketchfab.com/re1monsen) is licensed under Creative
Commons Attribution 4.0 (http://creativecommons.org/licenses/by/4.0/).

This is the original file as downloaded from Sketchfab. Its adapted version,
`public/models/monitor.glb`, is generated by `scripts/build-model.mjs` (ground
plane removed, transforms baked, screen glass given its own material and a
second UV set, meshes simplified and quantized, textures converted to WebP)
and is credited in the site's footer. Neither file is covered by the MIT
license of the repository's source code.

## desk_lamp.glb

by HASSAN (https://sketchfab.com/7ASSAN) is licensed under Creative Commons
Attribution 4.0 (http://creativecommons.org/licenses/by/4.0/).

`public/models/desk-lamp.glb`, is generated by `scripts/build-lamp-model.mjs`
