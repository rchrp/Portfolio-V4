## computer_terminal.glb

"Computer Terminal" (https://skfb.ly/6vrwA) by Chris Sweetwood is licensed
under Creative Commons Attribution-ShareAlike 4.0
(http://creativecommons.org/licenses/by-sa/4.0/).

This is the original file as downloaded from Sketchfab. Its adapted version,
`public/models/computer-terminal.glb`, is generated by
`scripts/build-model.mjs` (backdrop planes removed, screen glass split into its

of the repository's source code.
